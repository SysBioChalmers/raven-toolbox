# `raven_toolbox.localization`

Sub-cellular localisation — predictor-agnostic and partial-update friendly.
{func}`raven_toolbox.localization.predict_localization` is the MILP entry point; the loaders
parse predictor outputs (WoLF PSORT, DeepLoc 2) into the `gene × compartment` score frame the
algorithm consumes.
